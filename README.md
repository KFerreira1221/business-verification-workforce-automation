# AI-Powered Business Verification and Workforce Automation System

This project is a prototype system for automating business verification, document processing, workforce workflows and dashboard reporting.

## Project Goals

- Build a working business verification prototype
- Add document processing and OCR capability
- Create backend APIs for storing and retrieving verified business records
- Develop a functional dashboard
- Prepare a strong final report and presentation

## Tech Stack

- Python
- FastAPI or Flask
- PostgreSQL
- Pandas
- OCR tools such as Tesseract or EasyOCR
- Streamlit or Flask dashboard
- GitHub for version control
